Was it this data?

A fingerprint identifies the data without storing it

def fingerprint(table):
    row = con.sql("""
        SELECT COUNT(*), SUM(delivery_id),
               CAST(MIN(created_at) AS VARCHAR),
               CAST(MAX(created_at) AS VARCHAR)
        FROM deliveries""").fetchall()[0]
    return {"rows": int(row[0]),
            "sha": U.sha([str(x) for x in row])}
The peer's rerun givesFingerprintSo
The same numbersameReproduced
Another numbersameThe code or the environment differs
Another numberdifferentThe data changed: late corrections, a new export
The same numberdifferentLuck. Look again

A row count and a hash of a few totals is enough to tell two exports apart, costs one query, and contains no row. The helper's own version hashes every column. Operational tables change: parcels are corrected, scans arrive late. Without a fingerprint, a peer whose number differs cannot tell an error from an update.

Tracing

Every headline number ends in one of three states

Matched

A logged step produces it, and the rerun gives the same value.

Drifted

A logged step claims to produce it, and the rerun gives another value. The text and the code have parted.

No step

Nothing in the log produces it. It was typed, copied or computed somewhere else.

Trace from the report backwards. Start from each number a reader will quote and ask which line of the log made it.

Rerunning forwards, step by step, answers "does the log run?". Tracing backwards from the README answers "does the report come from the log?". They are different questions, and the lab's package passes the first and fails the second.

How a peer works

The peer reruns, traces and writes. The author repairs

The peer

  • Uses the package only, and asks nothing
  • Reruns every logged step
  • Traces every headline number
  • Writes a rerun log: what matched, what did not

The peer does not

  • Fix the package quietly
  • Pass a number because it "looks right"
  • Rerun the request through an assistant
  • Judge the conclusion: that is the review, a different task

An unverified step has two honest options

Verify it before the report goes out

Recompute the series, read the encodings, write the note. Fifteen minutes for a chart.
